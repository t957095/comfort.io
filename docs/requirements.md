# Option 1 requirements

- Enter classroom temperatures in Fahrenheit, one reading at a time.
- Show NORMAL for 68 F through 76 F, including both ends.
- Show WARNING outside the range and turn the LED on. Turn it off for a normal reading.
- Show the running average of the readings entered in the current run.
- Save each temperature and status to the CSV. Save the latest status to `status.txt`.
- Let the user set a different low and high limit when starting the program.
- Ask again when someone types something that isn't a valid number.
